# Smart Tabular Analyzer 发布检查清单

用于 V2.1 及后续小版本发布。按实际改动范围执行，但标记为“核心”的项目不应跳过。

## 1. 版本与范围

- [ ] 发布内容与项目定位一致：无需注册、浏览器本地处理、支持中文 CSV/Excel。
- [ ] 没有加入后端、数据库、账号、云存储或其他范围外依赖。
- [ ] `package.json`、README 当前版本、`report.js` 中的两处报告版本，以及 `index.html` 中 `style.css?v=` 和全部 10 个应用脚本 `?v=` 的版本参数保持一致。
- [ ] README、中文 README 和 `docs/` 与实际行为一致。
- [ ] 新增或修改的用户文件、测试夹具和截图不含真实个人数据。

## 2. 静态结构与依赖（核心）

- [ ] 根目录存在 `index.html`、`style.css` 和 10 个应用脚本：`parsing.js`、`profiling.js`、`format.js`、`stats.js`、`quality.js`、`app.js`、`importer.js`、`templates.js`、`report.js`、`script.js`。
- [ ] HTML 中本地资源使用相对路径，且文件实际存在。
- [ ] PapaParse、Chart.js、SheetJS 使用 `vendor/` 中的固定版本文件，页面没有 http(s) 外部脚本。
- [ ] 三个 vendor 文件的 SRI 哈希与实际文件一致，`vendor/licenses/` 中有对应许可证，根目录存在 `.nojekyll`。
- [ ] 页面不依赖构建步骤、后端接口或本地绝对路径。
- [ ] 10 个应用脚本逐个运行 `node --check` 都通过（`node --check a.js b.js` 只检查第一个文件，需要循环逐个检查）。

## 3. 自动化测试（核心）

- [ ] `npm test` 通过。
- [ ] `npm run test:regression` 全部通过。
- [ ] 100,000 行压力测试完成，未出现明显性能退化。
- [ ] `git diff --check` 通过。
- [ ] `.github/workflows/ci.yml` 语法校验通过。
- [ ] GitHub Actions 的 CI 在目标 commit 上通过。
- [ ] 若项目增加了 `lint` script，lint 通过。

## 4. 导入回归（核心）

- [ ] UTF-8 和 UTF-8 BOM CSV 可导入，中文字段名和值正常。
- [ ] GBK 和 GB18030 CSV 可通过编码选择导入。
- [ ] `.xlsx` 和 `.xls` 可导入。
- [ ] 多工作表 Excel 可选择工作表；空表和无表头表能给出错误。
- [ ] 空 CSV、只有表头、缺失表头、重复表头和多余单元格不会静默丢失数据。
- [ ] 表头上方有标题行（单格标题、合并单元格标题、“说明：…”这类两格行、空行）的 CSV 和 Excel 能导入，状态栏写明“表头在第 N 行，已跳过上方 K 行”，HTML / Markdown 报告里有“表头位置”。
- [ ] 第一行就是表头的文件（如 `tests/fixtures/stage3/订单表.csv`、`花名册.xlsx`）导入结果不变，状态栏和报告不出现“表头在第”。
- [ ] 识别不出表头所在行时，报错后面带上“第 N 行看起来像标题……”的提示；多工作表时提示出现在工作表选择面板里。
- [ ] 单列、单行、中文、Emoji、逗号、引号和换行文本可处理。
- [ ] 超过 25 MB、100,000 行或 200 列的数据会被明确拒绝。
- [ ] 连续上传多个文件不会保留旧筛选、字段配置、图表或工作表状态。

## 5. 字段与质量回归（核心）

- [ ] 数值、分类、日期和 ID 字段识别符合测试规则。
- [ ] 百分比、货币、千位分隔符、年份和歧义日期行为正确。
- [ ] 手动字段类型修正会重算分析，并显示转换失败数量。
- [ ] `ignore` 字段不会进入统计、图表、结论或模板候选项。
- [ ] 缺失值、完全重复行和 IQR 异常值结果正确。
- [ ] ID 字段重复值：`tests/fixtures/stage3/订单表.csv` 的订单号 DD1005 在第 6、19 行；`花名册.xlsx` 的工号、身份证号、手机号各有一个值在第 13、14、25 行，说明为“其中 2 行内容完全相同”；pill 依次为“ID 重复字段：1”和“ID 重复字段：3”；成绩表、门店报表写“ID 字段没有重复值（已检查：…）”。
- [ ] 文件行号与实际文件一致：用 Excel / WPS 打开 xlsx 看左侧行号，用记事本打开 CSV 看状态栏的行号；含表头上方标题行、表头下方空行和引号内换行的 CSV，行号是记录开始的那一行。
- [ ] `examples/sample-user-behavior.csv`：事件ID 逐值列出，用户ID、会话ID 显示“值大多重复出现”的提示，pill 为“ID 重复字段：1”。
- [ ] 把字段改成 ID 或从 ID 改成其他类型并应用后，ID 重复值随之更新；应用筛选后不变；没有数值字段的表也显示 ID 重复值。
- [ ] 疑似缺失值：`tests/fixtures/stage3/订单表.csv` 列出 5 条（下单日期「—」第 17 行、数量「—」第 12 行、金额「N/A」第 15 行、备注「N/A」第 29 行和「—」第 30 行），pill 为“疑似缺失值：4 个字段”；成绩表的“缺考”不列出，`examples/` 下的文件写“没有发现疑似缺失值。”。
- [ ] 在浏览器里各走一次：确认一条（金额「N/A」，缺失值总数 26 → 27，消息显示在疑似缺失值小节里，焦点移到消息上）、全部确认常见写法（缺失值总数 31）、撤销一条（恢复原来的数字）。每次都清除筛选；字段配置有未应用的修改时，点按钮只显示提示、不做任何改变。
- [ ] 确认后数据预览仍显示原值，导出的 CSV 与确认前逐字节相同；第二档写法（“无”“-” 等）附有“也可能是有效值”的提示，不包含在“全部确认常见写法”里。
- [ ] 字段类型修正和筛选不会修改 `state.rows`。

## 6. 筛选与分析回归（核心）

- [ ] 分类多选、搜索、全选和清空正常。
- [ ] 数值最小值/最大值筛选包含边界值。
- [ ] 日期开始/结束筛选包含边界日期。
- [ ] 分类、数值和日期条件组合时使用 AND。
- [ ] 清除筛选恢复全部原始记录。
- [ ] 筛选后预览、统计、图表、结论、自定义分析和模板结果同步刷新。
- [ ] 数据质量报告仍保持原始数据视角。
- [ ] 没有数值字段、分类字段或日期字段时显示空状态而不报错。
- [ ] 通用和五个场景模板只使用用户映射字段，不编造业务背景。

## 7. 图表与界面

- [ ] 每次重绘前旧 Chart.js 实例已销毁，没有图表叠加。
- [ ] 数值分布、分类 Top 10、日期趋势和自定义图表显示正确。
- [ ] 空筛选结果和无有效值时显示空状态。
- [ ] 桌面端图表布局、表格滚动和主要工作流可用。
- [ ] 手机窄屏无明显横向页面溢出，表格可在容器内横向滚动。
- [ ] 浏览器控制台没有未处理异常。

## 8. 导出回归（核心）

- [ ] 筛选后 CSV 行数与当前分析行数一致。
- [ ] 去重 CSV 基于原始数据，并保留每组重复记录的第一行。
- [ ] 两种 CSV 都保留原始字段顺序并包含 UTF-8 BOM。
- [ ] 中文、Emoji、逗号、引号和换行在导出 CSV 中正确转义。
- [ ] `=`, `@` 和非纯数值 `+` / `-` 前缀不会形成电子表格公式注入。
- [ ] HTML 和 Markdown 报告可导出并包含当前统计和结论。
- [ ] 报告的数据质量部分在“数值异常值”之后有“ID 字段重复值”一节，内容与质量页一致；质量摘要里有“ID 重复字段：N”。
- [ ] 报告的数据质量部分在“各字段缺失情况”之后有“疑似缺失值”一节：已确认的写法（被忽略的字段标“字段已忽略”）和还没确认的疑似值各一张表，与质量页一致；有检出或有确认时质量摘要里有“疑似缺失值：N 个字段”，没有检出的文件只写“没有发现疑似缺失值。”，摘要不变。HTML 和 Markdown 各检查一次。
- [ ] HTML 报告可离线打开，图表以内嵌 PNG 显示，无外部脚本依赖。
- [ ] 导出后可以继续筛选、修改字段和再次分析。
- [ ] 文件名不含非法字符或双向文本控制字符。

## 9. 安全与隐私（核心）

- [ ] 仓库中不存在密钥、Token、账号密码或私有 URL。
- [ ] 上传数据不会通过 `fetch`、XHR 或第三方 API 发送到服务器。
- [ ] 写入 `innerHTML` 的用户字段和值经过 `escapeHtml()`。
- [ ] Markdown 和 HTML 报告对用户内容进行对应转义。
- [ ] 没有新增 CDN 或其他外部请求；如确需新增，已经记录用途和隐私影响。

## 10. GitHub Pages 与发布后检查

- [ ] GitHub Pages 来源分支和目录配置正确。
- [ ] CI workflow 没有部署步骤，不会覆盖 Pages 发布设置。
- [ ] 在线首页、`style.css`、10 个应用脚本、`vendor/papaparse-5.4.1.min.js`、`vendor/chart-4.4.1.umd.min.js`、`vendor/xlsx-0.20.3.full.min.js`、示例 CSV 和截图资源返回 200。
- [ ] 在线演示可以加载 `examples/sample-data.csv`。
- [ ] 在线演示可以上传一份中文 CSV 和一份多工作表 Excel。
- [ ] README Live Demo 指向当前仓库的 Pages 地址。
- [ ] 发布后检查 GitHub Actions 和 Pages 部署状态均成功。
